# GearShare Mini website

## Install

From this directory:

```text
npm install
npm run dev
```

The development website is served by Vite at `http://localhost:5173`.

## Environment

Set the API base URL in `.env`:

```text
VITE_API_URL=http://127.0.0.1:8000
```

Use `.env.example` as the template.

## Tests

```text
npm test
```
